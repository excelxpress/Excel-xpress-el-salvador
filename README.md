# Mi Excel 📊

Aplicación web de hoja de cálculo tipo Excel, 100% en el navegador (sin servidor).

## Características

- ✅ Múltiples libros y hojas
- ✅ Fórmulas: `SUM`, `AVERAGE`, `MAX`, `MIN`, `COUNT`, `SUMIF`, `COUNTIF`, `IF`, `IFERROR`, `ROUND`, `ABS`, `POWER`, `SQRT`, `CONCAT`, `LEN`, `LEFT`, `RIGHT`, `TODAY`, `NOW`
- ✅ Formato: negrita, colores, moneda, porcentaje
- ✅ Insertar / eliminar filas y columnas
- ✅ Ordenar, buscar y reemplazar
- ✅ Comentarios en celdas
- ✅ Gráficos de barras
- ✅ Congelar primera columna
- ✅ Modo oscuro y zoom
- ✅ Protección con contraseña
- ✅ Compartir por enlace (edición o solo lectura)
- ✅ **Importar CSV y Excel (.xlsx / .xls)**
- ✅ Exportar a CSV
- ✅ Datos guardados en `localStorage`

## Cómo usar

1. Abre el archivo `index.html` en cualquier navegador moderno (Chrome, Firefox, Edge, Safari).
2. O súbelo a GitHub Pages / Netlify / Vercel para usarlo online.

### Importar un archivo Excel

1. Haz clic en el botón **📥**
2. Selecciona tu archivo `.xlsx`, `.xls` o `.csv`
3. Se cargarán automáticamente todas las hojas del archivo

## Demostración rápida

- Escribe valores en las celdas
- Usa fórmulas con `=` (ejemplo: `=SUM(A1:A10)`)
- Crea nuevos libros con el botón 📚
- Protege un libro con 🔒
- Comparte con el botón 🔗

## Tecnologías

- HTML + CSS + JavaScript puro
- [SheetJS](https://sheetjs.com/) para lectura de archivos Excel
- Sin dependencias de backend ni frameworks
